# hadid
## العمل بدون إنترنت
- `sw.js` يحفظ كل صفحات المكتبة وملفاتها والخطوط على الجهاز عند أول زيارة، ثم تعمل الصفحات بلا اتصال.
- التلاوة من EveryAyah تُحفظ آيةً آية عند سماعها، أو دفعة واحدة بزر «تنزيل تلاوة هذه الصفحة» تحت المشغّل.
- بعد إضافة أي ملف جديد إلى المكتبة شغّلي: `python3 tools/build_offline.py` لتحديث قائمة الملفات في `sw.js`.

## مقارنة التلاوة وفحص التجويد التجريبي

في «سمّعي بصوتك» بعد تسجيل آية:

- **قارني صوتي بالقارئ**: يرسم ارتفاع صوتك تحت صوت القارئ على مقياس زمني واحد، ويظلّل الأصوات الثابتة الطويلة (المدود والغنّة غالبًا)، ويقارن المدة وعدد الوقفات. لا يصدر حكمًا، ويعمل بلا إنترنت إذا كان صوت القارئ محفوظًا.
- **فحص التجويد (تجريبي)**: نموذج [HisnLabs/tajweed-v2](https://huggingface.co/HisnLabs/tajweed-v2) (Apache-2.0) يعمل داخل المتصفح عبر onnxruntime-web، ثم محرّك القواعد `imam.py` من المشروع نفسه منقولًا إلى JavaScript في `voice-check.js`. يُنزَّل النموذج مرة واحدة (نحو ٢٣ ميغابايت) ويُحفظ في الجهاز، ولا يُرسَل الصوت إلى أي خادم.
  - القراءة الصحيحة لكل آية (برواية حفص) في `tj/<رقم السورة>.json`، مولّدة بالأداة `tools/build_tajweed_refs.py` من مكتبة quran-transcript.
  - الحدود: يصف أحيانًا كلمة صحيحة بأنها خاطئة، ولم يُختبر على أصوات الأطفال، ولا يفهم الوقف وسط الآية ولا التكرار، والآية الأطول من ٣٠ ثانية لا يُفحص آخرها. للاسترشاد فقط، والحكم للمعلّم.
